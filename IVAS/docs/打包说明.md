# IVAS Windows 便携版打包说明

IVAS 使用 PyInstaller 生成目录式便携包。当前构建会把 Qt 资源中的 IVAS 标志、
Windows 图标和版本信息写入产物，并在默认情况下附带根目录的 SAM 3.1 checkpoint。

内部 Python 包、模型配置目标、导入路径和对外产品名称均使用 `IVAS`。

## 推荐的一键构建

在仓库根目录双击 `build_exe.bat`，或在 PowerShell 中运行：

```powershell
.\build_portable_exe.ps1
```

脚本会：

1. 使用项目内 `.venv`；若不存在，则从本机 `labeling` Conda 环境复制。
2. 安装 `requirements-portable.txt` 和固定版本的构建依赖。
3. 调用 `build_exe.spec` 收集 Python、PyQt5、模型后端、VLC 回退组件及资源。
4. 默认将 `sam3.1_multiplex_bf16.pt` 复制到运行包。
5. 对冻结程序执行 GUI 启动、IVAS 品牌/标志和 SAM 3.1 推理冒烟测试。

常用选项：

```powershell
# 明确需要不含 checkpoint 的较小运行包
.\build_portable_exe.ps1 -SkipCheckpoint

# 跳过冻结程序冒烟测试（不建议用于正式发布）
.\build_portable_exe.ps1 -SkipSmokeTest

# 清除 PyInstaller 分析缓存并完整重建
.\build_portable_exe.ps1 -Clean
```

## 产物

构建成功后，入口为：

```text
build\IVAS\IVAS.exe
```

发布时必须复制或压缩整个 `build\IVAS` 目录，不能只复制 `IVAS.exe`。
`_internal` 目录包含 Python、Qt、CUDA/模型依赖、`IVAS` 应用包和可选 checkpoint。
目标机器无需安装 Python 或 Conda；使用 CUDA 时仍需要兼容的 NVIDIA 驱动。

## 标志与版本资源

- 应用内标志源文件：`logo\logo.png`
- Windows 可执行文件图标：`logo\IVAS.ico`
- Qt 资源清单：`IVAS\icons.qrc`
- 已编译 Qt 资源：`IVAS\icons_rc.py`
- Windows 版本信息：`build_version_info.txt`

修改标志后，应重新生成 Qt 资源并重新打包：

```powershell
.\.venv\Scripts\pyrcc5.exe IVAS\icons.qrc -o IVAS\icons_rc.py
.\build_portable_exe.ps1 -Clean
```

正式发布前确认 About 对话框、任务栏/窗口图标、文件属性中的产品名均为 IVAS，
维护者为 zack zhao，并检查 `build\IVAS\SMOKE_TEST.log` 中所有阶段均通过。

## 文件兼容性

新文件默认使用 `ivas.yaml` 和 `project.ivas.json`。程序仍读取既有的 `ivas.yaml`、
`project.ivas.json` 以及带旧格式描述的标注 JSON，因此改名不会破坏已有数据。

## 常见问题

- **缺少 checkpoint**：把 `sam3.1_multiplex_bf16.pt` 放在仓库根目录，或在明确不需要
  模型的情况下使用 `-SkipCheckpoint`。
- **冻结程序启动失败**：查看 `build\IVAS\SMOKE_TEST.log`，并先用
  `.\.venv\python.exe main.py` 验证源码环境。
- **CUDA 不可用**：确认目标机器的 NVIDIA 驱动兼容打包时收集的 PyTorch/CUDA 运行时；
  CPU 路径不依赖 NVIDIA 驱动。
- **图标未更新**：确认 `icons_rc.py` 已重新生成，并使用 `-Clean` 重建以避免旧缓存。
